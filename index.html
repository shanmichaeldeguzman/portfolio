01

Capstone project · Job placement platform

EmploySmart

Source code ↗ Formerly live at employsmart.online

Overview

A municipal job-placement platform that connects jobseekers, employers, the Public Employment Service Office (PESO) and the City Livelihood office (CLCDO) in one system. Jobseekers upload a résumé and get ranked job matches; employers post jobs that PESO approves; staff get analytics and printable reports.

Problem addressed

Local job matching was manual and paper-based: résumés were read by hand, postings weren't verified, and staff had no live view of supply and demand. Jobseekers couldn't see why they did or didn't fit a role.

Objectives

  • Parse uploaded résumés (PDF/DOCX, including scanned files via OCR) into structured profiles
  • Rank jobs with an explainable, weighted match score
  • Give five roles (jobseeker, employer, PESO, CLCDO, admin) their own secure portals
  • Surface skill gaps and recommend training programs
  • Deploy to shared hosting and package for Android

Technologies

  • React 18
  • Vite
  • Tailwind CSS
  • PHP 8.1 REST API
  • MySQL
  • JWT
  • PDF.js + Tesseract.js
  • dompdf
  • Capacitor
  • Hostinger

My contribution

Sole developer (76 commits). I designed the 22-table MySQL schema, built the PHP API (16 controllers, JWT with refresh-token rotation, rate limiting, role-based access), the React front end for all five portals, the résumé parser and matching engine, and the Hostinger deployment.

02

Personal project · Life organizer

LifeSync

Live demo ↗ Source code ↗

Overview

An all-in-one personal organizer (tasks, calendar, notes, habits, finance, documents and goals) for Android, iOS, tablets and the web. It works fully offline and syncs automatically when the device reconnects.

Problem addressed

People juggle five or six apps to run their day, and most break without internet. LifeSync puts everything in one private place and keeps working on a spotty connection, without silently overwriting edits made on two devices.

Objectives

  • Deliver one codebase for web, Android and tablets
  • Store data locally first, then sync with conflict resolution
  • Protect every row with PostgreSQL Row Level Security
  • Provide reminders, recurring items, charts and CSV/JSON export
  • Test the API, database policies and UI on phone, tablet and desktop

Technologies

  • Ionic
  • Angular
  • TypeScript
  • Capacitor
  • Dexie / IndexedDB
  • Node.js
  • Express 5
  • Supabase Postgres
  • RLS
  • Vitest
  • Playwright
  • Vercel

My contribution

Sole developer. I built the architecture, data model and migrations, the offline sync engine, the Express API (zod validation, helmet, rate limiting), all ten modules of the UI, the Android build, and the test suites, then deployed the web app and API on Vercel.

Android APK available from GitHub Releases.

Project output

A live, installable PWA and Android app with a tested API, running at lifesync-roan-nine.vercel.app.

03

Cybersecurity · Teaching lab

JobLink OWASP Lab

Source code ↗ Intentionally vulnerable. Run locally only.

Overview

A deliberately insecure clone of a job-matching site that demonstrates five OWASP Top 10 (2021) risks. Each one comes with a step-by-step attack walkthrough and the secure fix I applied in EmploySmart.

Problem addressed

Security is easy to talk about and hard to see. This lab makes the vulnerabilities tangible so classmates and reviewers can see why prepared statements, access checks and secret management matter.

Objectives

  • A03 Injection: SQL injection on login and search
  • A01 Broken Access Control: unauthenticated admin page and IDOR
  • A07 Identification & Authentication Failures
  • A05 Security Misconfiguration: exposed secrets and debug output
  • A06 Vulnerable & Outdated Components, each with a documented fix

Technologies

  • HTML
  • CSS
  • Vanilla JS
  • PHP
  • MySQL
  • OWASP Top 10

My contribution

Sole author. I built the vulnerable front end and PHP back end, wrote the 600-line guide and the attack-scenario pages, and mapped each flaw to the hardening I applied in EmploySmart.

Project output

A self-contained security teaching kit, plus a measurable hardening checklist that shaped EmploySmart's production security.
